NFSU2 Save Editor

Open a Need for Speed: Underground 2 profile save (the file named after the profile, such as NFS Underground 2/YourGod/YourGod), change cash, unlocks, career events, save mode, difficulty and more, then save a copy. The file never leaves your browser. The checksums are made again the way the game writes them.

Drop a profile file here, or click to choose one No file extension, 54,966 bytes, starts with "20CM"

Profile

The name is stored in the profile; the folder and file must keep the same name, so rename all three if you want a different one.

Unlocks

Sets the same unlock bitfields as the 2005 NFSU2 Profile Creator. Columns are the career's five stages; each cell shows how many bits are already set. Click a cell to unlock that stage. Bytes are set to 0xFF (every bit), as the Profile Creator does.

CategoryStage 1Stage 2Stage 3Stage 4Stage 5

If widebody kits stay locked after unlocking all five stages of body parts, the game may also want that stage's unique-part reward, which this does not set.

Career

Decoded from the profile's event list and career block. The event list records the races, cover shoots and unique-part rewards the game has marked as won; ticking one adds it to that list. A tick is the game's won byte (record byte +6), not just a display.

Career block (19 records of 20 bytes)
Record+0+4+8+12+16

The first record is a header: +4 is the current car handle (CAREER_SLOT_n), +8 an unknown handle, +12 is 4 in these saves, +16 flags. The rest look like race results/times; their exact meaning is not mapped yet.

Cars in this profile

Read-only view of the career, customized and preset cars stored in the save. Type names come from the game's car table and the modded game's car folders; a name marked “(mod)” is a car the stock game does not have.

Garage (GARAGE.DAT)

Optional: drop the profile's GARAGE.DAT to see and edit the bonus/garage cars. The file is saved beside the profile; it holds the cars in slots 6–10 (and more in the modded game). The profile editor works without it.

GARAGE.DAT has no checksum; the header fingerprint is left as it is. Replace the file in the profile's folder after downloading.

Values at 0xD155

Sixteen values stored next to the profile name. Their meaning is not mapped yet, so change them with care. The first one reads as a float; the rest look like integers.

Save

The download has the profile's original file name (no extension) and its three checksums made again, so the game accepts it. Back up the original first, then replace the file in the profile's folder.
