NFSU2 Save Editor

Open a Need for Speed: Underground 2 profile save (the file named after the profile, such as NFS Underground 2/YourGod/YourGod), change cash, unlocks, save mode, difficulty and more, then save a copy. The file never leaves your browser. The checksums are made again the way the game writes them.

Drop a profile file here, or click to choose one No file extension, 54,966 bytes, starts with "20CM"

Profile

The name is stored in the profile; the folder and file must keep the same name, so rename all three if you want a different one.

Unlocks

Sets the same unlock bitfields as the 2005 NFSU2 Profile Creator. Columns are the career's five stages; each cell shows how many bits are already set. Click a cell to unlock that stage. Bytes are set to 0xFF (every bit), as the Profile Creator does.

CategoryStage 1Stage 2Stage 3Stage 4Stage 5

If widebody kits stay locked after unlocking all five stages of body parts, the game may also want that stage's unique-part reward, which this does not set.

Cars in this profile

Read-only view of the career, customized and preset cars stored in the save. Type names come from the game's own car table; a hash that is not one of them is a mod car.

Values at 0xD155

Sixteen values stored next to the profile name. Their meaning is not mapped yet, so change them with care. The first one reads as a float; the rest look like integers.

Save

The download has the profile's original file name (no extension) and its three checksums made again, so the game accepts it. Back up the original first, then replace the file in the profile's folder.
